# Velociraptor Laboratory

Laboratory project for endpoint monitoring,
digital forensics and incident response.

## Environment

- SERVER-VELO: Ubuntu, Velociraptor Server
- UBUNTU-CLI: Ubuntu 24.04, Velociraptor Client
- WINDOWS-CLIENT: Windows 11, Velociraptor Client
- Virtualization: Oracle VirtualBox

## Automation

- linux_client.yml: Linux agent management
- linux_client_install.yml: Linux agent installation
- windows/manage_velociraptor.ps1: Windows agent management
- windows/install_velociraptor.ps1: Windows agent installation

## Detection and Monitoring

- vql/lab10_alert.sql: Test alert generation
- vql/lab10_verify.sql: Alert verification
- vql/lab10_monitor.yaml: Server event monitoring

## Evidence

Laboratory screenshots are stored separately
from sensitive forensic evidence.

## Security

Private keys, agent configurations and raw
forensic artifacts must not be published.
